CUSTOM LEVELS - Blobby Volley 2 HD

DE: Lege hier pro Level einen eigenen Ordner an. Der Ordnername erscheint im Spiel.
EN: Create one folder per level here. Its folder name appears in the game.

Mein Level / My Level/
    background.webp  (oder/or background.png, erforderlich/required)
    music.ogg        (optional, Musik oder Hintergrundgeraeusch / music or ambience, loop)
    victory.ogg      (optional, Siegeston / victory sound, once)
    bums.ogg         (optional, Ballkontakt / impact)
    chat.ogg         (optional, Chat)
    pfiff.ogg        (optional, Pfiff / whistle)

DE: Fuer alle Sounds ist auch WAV erlaubt. Bei doppelten Dateien wird OGG vor WAV,
WebP vor PNG verwendet. Fehlende oder defekte Sounds verwenden die Standardsounds.
Neue Musikrollen bleiben still, solange es dafuer keinen Standardsound gibt.
Keine Konfigurationsdatei noetig. Auswahl beim Oeffnen der Optionen aktualisieren.
EN: WAV is also accepted for all sounds. OGG takes priority over WAV; WebP over PNG.
Missing or broken sounds use the built-in defaults. Missing default music stays silent.
No configuration file needed. Reopen the options to discover newly added folders.

DE: Hintergrund am besten 16:9. In 4:3 werden nur die Seiten abgeschnitten.
Die Netzstange muss mittig bleiben; als Vorlage ein Bild aus Levels kopieren.
EN: Prefer a 16:9 background. Classic 4:3 crops the sides.
Keep the net pole centered; copy an existing background from Levels as a reference.

menu.ogg gehoert zu den globalen Sounds, nicht in einen Levelordner.
menu.ogg belongs to global sounds, not individual level folders.
